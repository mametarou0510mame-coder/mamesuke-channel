# Instagram 自動投稿キュー

1投稿 = 1フォルダ（`posts/<日付>_<名前>/`）

- `video.mp4` … リール動画（縦 1080x1920）
- `caption.txt` … キャプション（ハッシュタグは5個まで）
- `post.json` … `publish_at`（日本時間なら `+09:00` 付き）。`"hold": true` を入れると投稿しない
- `posted.json` … 投稿後に自動で作られる（投稿済みの印。消すと再投稿されるので注意）

毎時17分頃にチェックし、公開時刻を過ぎた未投稿のものを投稿します（GitHubの混雑で数十分遅れることがあります）。
